### 2층 — 경로 판정 (182건)

**롤업 규칙** — 구성 링크 판정의 보수적 최솟값 (X > H > C > A)

| 구성 링크 | 경로 판정 | 계산 반영 |
|-----------|-----------|-----------|
| 하나라도 X | X | 미반영 |
| X 없고 H 있음 | H | 구조 유지, 효과 0 |
| C 있음 | C | 반영 + 단서 합집합 표시 |
| 전부 A | A | 반영 |

**경로 고유 축 P2 (이중계상·중복지름길)** — 링크만 봐서는 판정 불가.
같은 정책·같은 싱크로 가는 경로들의 2030 기여가 완전히 일치하면 중복이다.
P2는 롤업보다 우선한다 (구성 링크가 모두 A여도 중복이면 X).

### 판정 원칙

- **단일 판정** — 4모델 합의 규칙(기준서 §6) 미적용
- **보수적 A 기준** — 위양성(부정합을 정합으로 판정) 최소화
  - 판단 불가 축이 하나라도 있으면 최소 C
  - 계수 출처가 R4 확인순서 ①~④(가이드라인·부처고시·국가계수·외부사업방법론) 밖이면 A 아님
- **H 처리** — 계수 미확보 링크에 잠정 대리계수를 부여하고 산정근거를 기재해 C로 전환.
  살릴 수 있는 경로를 살리는 것을 우선한 결정이며, 잠정값임을 `계수 출처`에 명시했다.
  그 결과 H 판정은 0건이다.

### 발열량 기준 불일치 (3건)

환경부고시 제2021-10호 별표12의 배출계수는 **순발열량(NCV)** 기준인데,
1TOE=41,868MJ는 **총발열량(GCV)** 기준이다. 두 값을 곱하면 6~7% 과대산정된다.
입력 파일의 산출식 주석이 이미 권장값 2.88/2.81/2.85를 적어 두었으나 W에는 반영돼 있지 않았다.

### ★연동보정

`D204→I07`(26.101)은 산출식에 "검산 26.101×3.065 = 80.0"이 명시돼 있어
가이드라인 4-25 앵커값 80 tCO₂eq/척에 묶여 있다.
`I07→I08`만 2.88로 바꾸면 이 앵커가 75.17로 조용히 깨지므로 80÷2.88=27.7778로 재산정했다.
검산: 27.7778 × 2.88 = 80.000 (복원 확인).

계수를 바꾸지 않은 C 링크 22건은 권장이 "현행 유지 + 조건 부착"인 것들이다
(부문 이동, 상한값 표시, 배분 규칙 등). 값이 아니라 단서가 붙는 판정이라 `조치·조건`에 기재했다.

## 미결 사항

1. **ZEB 예비인증/본인증 배타성** — 권장계수 확정 불가. 예비인증 129,300,000과 본인증 43,008,000이
   같은 D14 노드로 합산되는데 두 집합이 배타적인지(별개 건물) 포함관계인지(같은 건물의 인증 단계)
   확인할 자료가 이 배치에 없다. 포함관계면 한쪽을 0으로 둬야 하고, 선택에 따라 SD01 기여가
   -1,293,000과 -430,800 사이에서 3배 차이 난다.

2. **신규 노드 4개 미등재** — `I82`(수송 전력 소비량) · `I84`(수송 휘발유 대체량) ·
   `I34`(생활 에너지 절감량) · `I103`(바이오가스 생산량)이 `project-outcome/pen/PEN_nodes_links.xlsx`
   NODES에 없다. 채택 시 등재가 선행돼야 빌드된다.

3. **ZEB 투입단위 표기 오류** — 투입단위가 '만㎡'로 돼 있으나 계산은 ㎡ 기준으로 수행된다
   (129,300,000 × 0.0044964 × 2.224 = 1,292,999로 표값과 일치). 라벨 정정 필요.

4. **중복지름길 탐지 로직** — 항등 링크를 통과하는 지름길을 놓친다. 경로 생성기 보완 필요.

5. **SD01 미러 생성 규칙** — 회계경계 예외 필터가 없어 `I109→SD01` 같은 링크가 만들어진다.

6. **지역 심사와의 정합성** — 기준서 §9가 지시한 "8월 27일 지역 심사 규칙 확인"이 미수행이다.
   지역 경로 20건 표본 재심사로 같은 판정이 나오는지 확인해야 한다.

7. **PEN 본체 미반영** — 이번 수정은 심사결과 파일 안에서만 이뤄졌다.
   `project-outcome/pen/PEN_nodes_links.xlsx`의 `base_weight`와 `sim_cache/`는 건드리지 않았다.
   병합하려면 NODES 등재 + LINKS 추가 + 사이클 검사 + 재빌드가 함께 가야 한다.
